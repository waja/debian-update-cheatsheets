## Debian update cheatsheets

Please **DON'T** run those scripts unattended or even start them on shell. They are intended as copy & paste for usual (or even unusual) situations you might need to handle when upgrading your Debian installation. Please consult the [Debian release notes](https://www.debian.org/releases/stable/releasenotes) **BEFORE** you upgrade your system.

If you are not experienced updating Debian (based) systems, please keep away from this cheatsheet!

## PHP package updates

The following branch contains instructions for updating installed PHP packages from [packages.sury.org](https://packages.sury.org/php/) on Debian 11, 12 and 13. It is intended for carefully updating PHP packages while keeping the active PHP version in focus, rather than upgrading the Debian distribution itself.

* [update-php-packages.sury.org](https://github.com/waja/debian-update-cheatsheets/tree/update-php-packages.sury.org)
